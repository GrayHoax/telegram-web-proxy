# Пошаговая инструкция для тех, кто не связан с ИТ

> ⚠️ **Важно.** Этот репозиторий предназначен **не для создания технических средств
> обхода блокировок**, а для изучения современных технологий, применяемых в Telegram.
> Всё, что описано ниже, – учебный эксперимент. Продолжая использовать решения из
> этого репозитория, вы самостоятельно берёте на себя всю ответственность за их
> применение и соблюдение законодательства своей страны.

Инструкция написана так, чтобы её мог выполнить человек, который ни разу не работал
с серверами. Нужно будет в точности повторять команды. Понимать их не обязательно.
На всё уйдёт 30–60 минут.

---

## Что получится в итоге

- У вас будет свой сайт по адресу вроде `https://anna-garden.ru`. Это обычная личная
  страничка, которую для вас придумает нейросеть.
- На том же сервере будет работать учебный WEB-прокси Telegram. Он спрятан по
  секретному адресу, о котором знаете только вы.
- Вы получите ссылку вида `https://t.me/webproxy?server=...&secret=...` для клиента
  Telegram, который поддерживает тип прокси WEB.

> ℹ️ Тип прокси WEB пока экспериментальный. Он есть не во всех версиях Telegram, а
> только в тестовых сборках, которые поддерживают эту технологию. Если ваш Telegram
> не понимает такую ссылку, значит, поддержки в нём ещё нет.

---

## Шаг 1. Что понадобится

1. **Сервер (VPS).** Это компьютер в интернете, который арендуют у хостинг-провайдера
   примерно за 300–700 ₽ в месяц. При заказе выберите:
   - операционная система: **Ubuntu 24.04** (подойдут также Ubuntu 22.04 и Debian 12);
   - процессор: обычный **x86_64 / AMD64**, не ARM;
   - память: от **1 ГБ**, диск: от **10 ГБ**;
   - обязательно **публичный IPv4-адрес** (обычно он входит в тариф).

   После оплаты провайдер пришлёт **IP-адрес** (например, `203.0.113.25`) и
   **пароль пользователя root**. Сохраните их.

2. **Доменное имя** – адрес сайта, например `anna-garden.ru`. Его покупают у
   регистратора доменов, обычно за 200–900 ₽ в год. Можно использовать и поддомен
   уже имеющегося домена, например `home.mysite.ru`.

3. **Компьютер** с Windows 10/11, macOS или Linux и браузер.

---

## Шаг 2. Привяжите домен к серверу

1. Откройте личный кабинет регистратора домена и найдите раздел
   **«DNS»** / **«Управление зоной»** / **«DNS-записи»**.
2. Добавьте запись:
   - **Тип:** `A`
   - **Имя (хост):** `@` (если используете сам домен) или, например, `home` (для поддомена `home.mysite.ru`)
   - **Значение:** IP-адрес вашего сервера
3. Сохраните. Изменения расходятся по интернету от 5 минут до нескольких часов.

Проверить можно на своём компьютере. На Windows нажмите `Win + R`, введите `cmd`,
нажмите Enter и выполните:

```text
nslookup anna-garden.ru
```

Если в ответе есть IP-адрес вашего сервера, всё готово.

---

## Шаг 3. Подключитесь к серверу

**Windows 10/11.** Нажмите `Win + X` и выберите «Терминал» (или «Windows PowerShell»).
Введите, заменив IP на свой:

```text
ssh root@203.0.113.25
```

- На вопрос `Are you sure you want to continue connecting` напишите `yes` и нажмите Enter.
- Введите пароль из письма провайдера. **Символы при вводе не отображаются** – так и
  должно быть. Вставить пароль можно правой кнопкой мыши.

**macOS.** Откройте программу «Терминал» и выполните ту же команду.

Если появилась строка вида `root@server:~#`, вы на сервере.

---

## Шаг 4. Установите прокси одной командой

Скопируйте команды по одной, вставьте их в окно терминала (правой кнопкой мыши) и
нажмите Enter. Вместо `anna-garden.ru` укажите свой домен.

```bash
apt update && apt install -y git
```

```bash
git clone https://github.com/GrayHoax/telegram-web-proxy.git
```

```bash
cd telegram-web-proxy && sudo ./scripts/install.sh --hostname anna-garden.ru
```

Скрипт:

1. покажет предупреждение об ответственности – напишите `да` и нажмите Enter;
2. спросит e-mail для сертификата – можно указать свой или просто нажать Enter;
3. сам установит Docker, всё скачает и соберёт (это **5–10 минут**, на экране будет
   много текста – это нормально);
4. в конце выведет блок примерно такого вида:

```text
Proxy server (enter manually): anna-garden.ru/v6hhi3sgp6vlnuat
Proxy secret (enter manually): a248b37dcc44a88cace2f457bfa99e84
Proxy link:                    https://t.me/webproxy?server=anna-garden.ru%2Fv6hhi3sgp6vlnuat&secret=cKJIs33...
```

**Сохраните эти строки в надёжном месте и никому не пересылайте.** Тот, у кого есть
ссылка, может пользоваться вашим прокси.

Проверьте в браузере адрес `https://anna-garden.ru` – откроется временная страница
«Сайт обновляется». На следующем шаге замените её своей.

---

## Шаг 5. Сделайте свою главную страницу с помощью нейросети

1. Откройте [chat.openai.com](https://chat.openai.com) (ChatGPT) или
   [chat.deepseek.com](https://chat.deepseek.com) (DeepSeek) и войдите в аккаунт.
2. Откройте файл [SITE-PROMPT.md](SITE-PROMPT.md), выберите тему из таблицы (например,
   «Дачник и садовод») и скопируйте большой текст промпта из раздела «Шаг 2».
3. Вставьте его в чат, впишите свою тему в квадратные скобки и отправьте.
4. Нейросеть пришлёт два блока кода: `index.html` и `404.html`.
5. На сервере (в том же окне терминала) выполните:

   ```bash
   nano ~/telegram-web-proxy/site/index.html
   ```

   Откроется пустой редактор. В чате нажмите «Copy» над блоком `index.html`, затем
   щёлкните правой кнопкой мыши в окне терминала – текст вставится. Сохраните:
   `Ctrl + O`, затем `Enter`. Выйдите: `Ctrl + X`.
6. Так же создайте файл `404.html`:

   ```bash
   nano ~/telegram-web-proxy/site/404.html
   ```

7. Перезапустите контейнер, чтобы он подхватил страницу:

   ```bash
   cd ~/telegram-web-proxy && docker compose restart
   ```

8. Обновите в браузере `https://anna-garden.ru`. Должен открыться ваш новый сайт.

---

## Шаг 6. Подключите Telegram

**По ссылке.** Откройте сохранённую ссылку `https://t.me/webproxy?...` (или
`tg://webproxy?...`) на устройстве, где установлен клиент Telegram с поддержкой WEB-прокси,
и подтвердите добавление прокси.

**Вручную.** В настройках клиента найдите **Настройки → Продвинутые настройки → Тип
соединения → Использовать прокси → Добавить прокси → WEB** и введите:

- **Сервер:** значение из строки `Proxy server` (вместе с частью после `/`);
- **Секрет:** значение из строки `Proxy secret`.

Названия пунктов меню могут немного отличаться в разных сборках.

## Полезные команды

Все команды выполняются на сервере в папке проекта (`cd ~/telegram-web-proxy`).

| Что нужно | Команда |
|---|---|
| Ещё раз показать ссылку | `sudo ./scripts/show-link.sh` |
| Перезапустить (после смены страницы) | `docker compose restart` |
| Посмотреть журнал работы | `docker compose logs --tail 100` |
| Обновить до новой версии | `sudo ./scripts/update.sh` |
| Остановить | `docker compose down` |
| Запустить снова | `docker compose up -d` |

## Если что-то не работает

| Признак | Что сделать |
|---|---|
| Сайт не открывается совсем | Проверьте шаг 2 (`nslookup`). В панели хостинга откройте входящие порты **80** и **443**, если там есть межсетевой экран (firewall). |
| Браузер пишет, что сертификат недействителен | Подождите 5 минут после первого запуска. Если не помогло, домен ещё не указывает на сервер (шаг 2). Затем выполните `docker compose restart`. |
| Скрипт пишет «нужен сервер x86_64» | Вы арендовали сервер на ARM. Закажите тариф на x86_64/AMD64. |
| Telegram не понимает ссылку | В вашей версии Telegram нет поддержки WEB-прокси. |
| Telegram долго «подключается» | Выполните `docker compose logs --tail 100` и поищите строки `ERROR` или `Disconnected from RPC Middle-End`. Во втором случае впишите в файл `.env` строку `MTPROXY_PUBLIC_IP=IP-вашего-сервера` и выполните `docker compose up -d`. |
| Показывается «Сайт обновляется» вместо вашей страницы | Файл не сохранился или называется иначе. Выполните `ls ~/telegram-web-proxy/site` – там должен быть `index.html`. |

## Безопасность – коротко

- Не публикуйте ссылку и секрет в открытых чатах и соцсетях.
- Если ссылка попала к посторонним, смените секрет. Откройте файл настроек
  командой `nano .env`, сотрите значение после `TPROXY_SECRET=` (строка должна
  стать `TPROXY_SECRET=`), сохраните и выполните `docker compose up -d` и
  `sudo ./scripts/show-link.sh`. Старая ссылка перестанет работать.
- Раз в месяц запускайте `sudo ./scripts/update.sh`.
