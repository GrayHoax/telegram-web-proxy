# Генерация главной страницы через ChatGPT или DeepSeek

> ⚠️ **Важно.** Этот репозиторий предназначен не для создания технических средств
> обхода блокировок, а для изучения современных технологий, применяемых в Telegram.
> Продолжая использовать решения из этого репозитория, вы самостоятельно берёте на
> себя всю ответственность за их применение.

Контейнер показывает на главной странице домена обычный сайт – например, личную
страничку увлечённого человека. Прокси при этом доступен только по случайному адресу
(`https://ваш-домен/<случайный-путь>/`) и только тем, кто знает секрет. Всем
остальным – и людям, и поисковым роботам – отдаётся только сайт.

Готовой страницы в репозитории намеренно нет: если у тысяч серверов одинаковая
заглушка, её легко узнать. Поэтому каждый генерирует **свою** уникальную страницу
с помощью нейросети:

- ChatGPT – <https://chat.openai.com>
- DeepSeek – <https://chat.deepseek.com>

## Шаг 2. Скопируйте промпт

Откройте ChatGPT или DeepSeek, начните новый чат, вставьте текст ниже целиком
и замените значения в квадратных скобках (или оставьте `[придумай сам]`).

```text
Ты – опытный веб-дизайнер и копирайтер. Создай уникальный статический сайт –
личную страницу вымышленного человека.

Исходные данные:
- Тема: [например: дачник и садовод из Подмосковья, выращивает томаты]
- Имя и возраст персонажа: [придумай сам; вымышленный человек, не реальный]
- Город или регион: [придумай сам]
- Настроение и стиль оформления: [например: тёплый, уютный, светлые тона]
- Язык сайта: русский

Что нужно сделать:
1. Файл index.html – главная страница. Разделы: шапка с именем и короткой фразой
   о себе; «Обо мне» (2–3 абзаца живым языком, с бытовыми деталями); 3–5 заметок
   или записей блога с датами за последние 1–2 года (по 1–2 абзаца каждая);
   раздел с увлечениями, проектами или услугами по теме; блок с «фотографиями»,
   нарисованными как простые иллюстрации на встроенном SVG; подвал с годом и
   строкой «Сделано вручную». Общий объём текста – 700–1200 слов.
2. Файл 404.html – страница «Страница не найдена» в том же стиле со ссылкой «/».

Строгие технические требования:
- Каждый файл полностью самодостаточен: весь CSS внутри тега <style>, картинки –
  только встроенный SVG или CSS. Никаких внешних ресурсов: без CDN, без Google
  Fonts, без внешних картинок, без iframe.
- Без JavaScript. Если без него никак – только маленький встроенный скрипт без
  обращений к сети, без cookie, без localStorage и без Service Worker.
- Без счётчиков, аналитики, рекламы, кнопок соцсетей и форм, отправляющих данные.
  Для связи – только текстовый e-mail вида name@example.com.
- Адаптивная вёрстка (телефон и компьютер), семантические теги HTML5,
  <meta charset="utf-8">, <meta name="viewport">, осмысленные <title> и
  <meta name="description">. Ссылки внутри сайта – только на «/» или на якоря
  вида «#about».
- Оригинальный дизайн: выбери необычную, но спокойную палитру, нестандартную
  сетку и шрифты из системного стека (font-family: Georgia, serif и т. п.).
  Не используй шаблонные заготовки вроде Bootstrap.
- Человек и все детали – вымышленные. Не упоминай реальных людей, компаний,
  брендов, а также слова «прокси», «VPN», «Telegram», «обход», «сервер».

Формат ответа: сначала полный код index.html в одном блоке кода, затем полный код
404.html в отдельном блоке кода. Без пояснений между блоками и без сокращений
вида «…остальной код…».
```

### Если нужен сайт из нескольких страниц

Добавьте в конец промпта:

```text
Дополнительно сделай страницы about.html и blog.html в том же стиле. В меню всех
страниц ссылки указывай точными адресами: «/», «/about.html», «/blog.html».
Каждую страницу выдай отдельным блоком кода.
```

### Если результат не понравился

Напишите в том же чате, например:

- «Сделай дизайн менее шаблонным, смени палитру и расположение блоков.»
- «Добавь ещё две заметки в блог, тексты сделай более живыми и конкретными.»
- «Код оборвался – пришли index.html целиком заново.»

## Шаг 3. Сохраните файлы

1. Нажмите в чате кнопку **Copy / Копировать** над блоком кода `index.html`.
2. Сохраните его в папку `site/` репозитория под именем **`index.html`**
   (кодировка UTF-8). Аналогично сохраните `404.html` и другие страницы.
   - На сервере это проще всего сделать так: `nano ~/tgweb-proxy-docker/site/index.html`,
     вставить текст (правая кнопка мыши или Shift+Insert), сохранить `Ctrl+O`, `Enter`,
     выйти `Ctrl+X`.
   - С компьютера можно загрузить файлы программой WinSCP / FileZilla или командой
     `scp index.html 404.html root@IP-сервера:~/tgweb-proxy-docker/site/`.
3. Откройте файл в браузере у себя на компьютере и проверьте, что всё выглядит
   нормально и в тексте нет лишних упоминаний.
4. Примените изменения:

   ```bash
   docker compose restart          # Docker Compose
   ./k8s/deploy.sh --site site/index.html   # Kubernetes
   ```

5. Откройте `https://ваш-домен/` – должна показываться ваша страница.

## Что важно проверить

- Страница не должна подгружать ничего со сторонних сайтов (в браузере: F12 →
  вкладка «Сеть» → все запросы идут только к вашему домену).
- В коде нет `serviceWorker`, `navigator.serviceWorker`, `<iframe>`, внешних `<script src>`.
  Service Worker, установленный на домене, может перехватить служебную страницу
  прокси – апстрим прямо запрещает это (см. `PUBLIC_SITE.md` в tproxy-server).
- Ссылки в меню ведут на существующие файлы (`/about.html`, а не `/about`).
- Через некоторое время страницу стоит обновлять: добавлять «новые заметки» –
  живой сайт выглядит естественнее заброшенного.
